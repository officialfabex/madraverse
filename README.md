# Mądraverse Merch

Statyczna strona z jednym produktem, przygotowana do publikacji przez GitHub Pages.

- Katalog, szczegóły produktu i „O Mądraverse” działają na jednym adresie. Link produktu korzysta z `#madra-jedynus-plushie`.
- Przycisk „Udostępnij” kopiuje albo otwiera link bezpośrednio do widoku pluszaka.
- Koszyk pozwala dodać maksymalnie 10 sztuk. Przycisk „Kup” przenosi do informacji „O Mądraverse”; sklep nie realizuje prawdziwych zamówień.

## Publikacja

1. Wgraj zawartość folderu do głównego katalogu repozytorium GitHub.
2. Domyślna gałąź powinna nazywać się `main` (jeśli jest inaczej, zmień nazwę gałęzi w `.github/workflows/pages.yml`).
3. W **Settings → Pages** ustaw źródło na **GitHub Actions**.
4. Wypchnij zmiany do `main`. Workflow opublikuje stronę i wstawi pełny adres zdjęcia do metadanych podglądu linku.
